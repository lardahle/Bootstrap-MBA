# Bootstrap MBA

*An engineer's MBA, open-sourced.*

An Obsidian vault for learning business acumen: atomic notes from Texas A&M's Engineering
Entrepreneurship minor (Startup Fundamentals, Tech Company Management, and more), linked so
concepts build on each other.

**Use it:** clone it into your own vault (or open it as a vault on its own) and start at
[Global Index](Global%20Index.md). Copy, rewrite and extend it as you like.

**Contribute:** issues and pull requests are welcome: corrections, clearer explanations, or new
notes on topics the index lists.

Maintained by [Landon Dahle](https://landondahle.com) as a module of The ARX Foundation's
[Infinite Runway](https://github.com/The-ARX-Foundation/TheInfiniteRunway).
