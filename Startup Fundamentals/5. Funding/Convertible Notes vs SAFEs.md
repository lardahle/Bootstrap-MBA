| Feature | Convertible Notes | SAFEs |
|---|---|---|
| Instrument type | Debt that converts to equity | Agreement for future equity (not debt) |
| Interest | Accrues (5–10%) | None |
| Maturity date | Yes | None |
| Repayment obligation | Investor can demand it at maturity | None |
| Valuation cap | Common | Common |
| Discount rate | Common | Optional |
| MFN clause | Common | Sometimes |
| Complexity | Higher | Lower |
| Risk to founder | Must repay if no conversion | No repayment risk |

- **Which one?** Founders tend to prefer **SAFEs**: simpler, no interest, no deadline. Investors who want more protection push for **notes**, because the maturity date gives them leverage if the company stalls.
