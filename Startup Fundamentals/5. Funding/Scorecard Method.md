Values a pre-revenue startup by **comparing it to similar funded startups** in the same region and stage.

- Start with the **median pre-money valuation** of comparable deals, then adjust it by weighted factors. Common weights:
  - team 30%, market size 25%, product/technology 15%, competition 10%, marketing/sales channels 10%, need for more funding 5%, other 5%.
- Score each factor relative to the average (for example 150% for a stronger-than-typical team) and multiply through.
